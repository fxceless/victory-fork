# Ordered homogeneous indirect batches (Kelvaroq 0051 subset)

Source concept: https://github.com/stellarr-studio/kelvaroq/blob/1270c422adaef1e0f369f670138d8d29d8f6f4c3/native/patches/0051-indirect.patch (GPL-3.0; Kelvaroq contributors). AI-assisted adaptation to the newer upstream counted clamp window.

Set VICTORY_INDIRECT_BATCH=1 in a fresh process. Select the existing counted-table clamp window in single 64-lane-group mode for single-record non-counted, non-spread read-only Draw/DrawIndexed on the same backing buffer/kind/stride. Speculative ahead windows and prelude gathers are not selected in this mode. Every execution gets its own table entry, including repeats. A full window or different source/kind/stride starts another pass. Preserve the existing fallback and window closure at direct draws, dispatch, copies, list close/reset; additionally close before title barriers, pipe sync, value waits, deferred writes/copies/callbacks. No change to default or legacy clamp window when the option is unset.

This is NOT the full mixed-kind 0051 patch. Compute dispatches, mesh dispatches, count buffers and writer pipelines stay on the ordinary path. One group avoids cross-group scheduling differences in budget charging inside a batch; it does not prove all renderer work ordering. The actual existing clamp shader and resource lifetime path are retained. The source-extent check remains the existing gatherable check. No new shader ABI. CPU admission/capacity regression and a WARP counted-table test for repeated records and single-group budget order added; physical GPU ordering, fence/cut replay and paired gameplay tests required before promotion. Local build deferred during active benchmark.
